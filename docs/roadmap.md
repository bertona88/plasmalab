## First vertical slice — plasmoid-inspired toy

The user’s 2026-10-04 implementation mission selected the [plasmoid/reconnection-inspired toy](experiments/plasmoid-ecology.md), superseding the assistant’s earlier [oscillator proposal](experiments/charge-separation.md). The toy is an invented local-rule universe, not a quantitative plasma solver.

- [x] Implement one bounded 2D model in Rust, with validated parameter ranges and fixed toy timesteps.
- [x] Connect it through a narrow WASM/worker adapter; keep authoritative evolution out of TypeScript.
- [x] Run/pause/step/reset, choose four presets, change parameters and perturb the field directly.
- [x] Keep simulation time independent of frame rate; slower execution reduces simulated progress.
- [x] Show model assumptions and live stress, threshold-event and candidate-region observations.
- [x] Detect modest candidate regions as observations with frame-local labels and no evolution authority.
- [x] Save a versioned checkpoint in IndexedDB, export/import it, and restore actual state with intervention history.
- [x] Reject invalid state and unsupported save/model versions before replacing a run.
- [x] Complete the recorded scientific, build and browser acceptance checks in [toybox evidence](evidence/toybox.md).

**Gate:** a person discovers a cause-and-effect relationship, saves it, and returns to it with assumptions and state intact. Passing invariant and interaction checks supports this toy loop; it does not validate physical reconnection or establish MHD/PIC accuracy.

## Rung 2 — Browser Plasma Laboratory

- [ ] Deepen a selected problem into a spatial plasma reference model with declared correspondence to earlier experiments.
- [ ] Record convergence, reference errors, stability limits, and total execution costs.
- [ ] Add accelerated execution where measured need and reference comparisons justify it.
- [ ] Observe → track → predict: candidates gain histories and testable shadow forecasts, with no evolution authority.
- [ ] Compare predictions to reference outcomes for named observables and horizons; test new interventions where practical.

**Gate:** a user can inspect a structure or prediction, compare it with a reference outcome, and understand its errors and limits. Preserve the Toybox.

## Rung 3 — Adaptive SELFS Laboratory

- [ ] Choose one narrow representation transition with explicit physical responsibility and exchanges.
- [ ] Specify discarded information, uncertainty, validity criteria, and a viable recovery or stop strategy.
- [ ] Advise before acting: proposals → supervised trials → guarded automatic decisions.
- [ ] Test loss of validity and recovery against a sufficiently detailed reference path.
- [ ] Evaluate matched accuracy and prediction horizon, including discovery, tracking, prediction, checking, coupling, transition, and recovery costs.

**Gate:** one useful transition with measured accuracy, full cost, and demonstrated failure handling. No general speedup claim follows. Preserve both Toybox and Laboratory.

## Deferred
