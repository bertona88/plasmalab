# Delivery ladder

The source [ladder](ladder.md) defines the destination. This checklist tracks delivery; unchecked items are not implemented. Advance when evidence earns the next responsibility.

## Foundation — implemented

- [x] Preserve direction and SELFS source documents.
- [x] Create Rust and Svelte/TypeScript workspaces with explicit ownership.
- [x] Add a truthful browser shell, scientific requirement validation, and CI configuration.
- [x] Define the first proposed experiment and scientific evidence expectations.

## First vertical slice — next

Proposed thread: [charge separation and its restoring response](experiments/charge-separation.md).

- [ ] Implement one normalized oscillator model in Rust with an analytic reference and convergence checks.
- [ ] Connect it through a narrow WASM/worker adapter; keep authoritative evolution out of TypeScript.
- [ ] Set initial conditions, apply an explicit impulse, run/pause/step/reset, and inspect named observations.
- [ ] Keep simulation time independent of frame rate; make overload reduce display cadence or simulated progress.
- [ ] Show the assumptions, units, model version, and numerical diagnostics alongside the visualization.
- [ ] Save locally, export/import, and reopen an actual state, retaining interventions and provenance.
- [ ] Verify the complete loop in the browser, including unsupported save versions and recovery from storage failure.

**Gate:** a person discovers a cause-and-effect relationship, saves it, and returns to it with assumptions and state intact. The scaffold alone does not pass this gate.

## Rung 1 — Plasma Toybox

- [ ] Ship the first full loop above; make it rewarding to open and explore.
- [ ] Add further experiments only when each introduces a useful question and preserves the existing loop.
- [ ] Clearly label invented/toy rules and distinguish them from physical approximations.

## Rung 2 — Browser Plasma Laboratory

- [ ] Deepen a selected problem into a spatial plasma reference model with declared correspondence to earlier experiments.
- [ ] Record convergence, reference errors, stability limits, and total execution costs.
- [ ] Add accelerated execution where measured need and reference comparisons justify it.
- [ ] Observe → track → predict: candidates gain histories and testable shadow forecasts, with no evolution authority.
- [ ] Compare predictions to reference outcomes for named observables and horizons; test new interventions where practical.

**Gate:** a user can inspect a structure or prediction, compare it with a reference outcome, and understand its errors and limits. Preserve the Toybox.

## Rung 3 — Adaptive SELFS Laboratory

- [ ] Choose one narrow representation transition with explicit physical responsibility and exchanges.
- [ ] Specify discarded information, uncertainty, validity criteria, and a viable recovery or stop strategy.
- [ ] Advise before acting: proposals → supervised trials → guarded automatic decisions.
- [ ] Test loss of validity and recovery against a sufficiently detailed reference path.
- [ ] Evaluate matched accuracy and prediction horizon, including discovery, tracking, prediction, checking, coupling, transition, and recovery costs.

**Gate:** one useful transition with measured accuracy, full cost, and demonstrated failure handling. No general speedup claim follows. Preserve both Toybox and Laboratory.

## Deferred

Universal world state, unrestricted model mixing, automatic representation discovery, generic multirate scheduling, distributed execution, and a comprehensive SELF taxonomy. No preallocated crate tree is needed for these ideas.
